Analyze the repository before making any modifications.

Tasks:

1. Read all relevant files inside the `.ai` directory.
2. Understand the overall project architecture.
3. Identify modules, services, routers, schemas, and models.
4. Understand the business workflows.
5. Identify reusable components.
6. Identify authentication and authorization flow.
7. Identify coding conventions.
8. Identify existing design patterns.
9. Identify dependencies between modules.

Do not modify any files.

Return a summary containing:

- Project architecture
- Business workflow
- Module relationships
- Coding conventions
- Existing reusable components
- Risks to avoid during implementation
